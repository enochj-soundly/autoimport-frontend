# AutoImport Frontend

React + Vite customer-facing app for the AutoImport vehicle platform.

## Quick Start

```bash
npm install
cp .env.example .env
npm run dev
```

## Tech Stack

- React 18 + Vite 5
- React Router v6
- Zustand (state)
- Axios + React Query (API)
- Lucide React (icons)

## Deploy

```bash
npm run build
npx vercel
```
